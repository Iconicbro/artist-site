# Artist Site — Juno Hale concept

Motion-rich one-page site for a singer-songwriter (concept, placeholder content).

**Live preview:** served by GitHub Pages from this repo.

## Editing content
- Open the live page with `?edit` (or `#edit`) to use the built-in editor, then download `content.json`.
- Replace `content.json` in this repo with the new file (Add file → Upload files). The page reads it on load — no rebuild.
- `index.html` is a self-contained build (React, styles, Anton font all inlined).

Production build for Hostinger and the full React source are delivered separately.
